# UI 仕様

サイトの UI 構成、レイアウト、各ページの仕様を定義する。

## 全体レイアウト

サイトは画面最左にメインナビゲーションを持つ縦型のレイアウトを基本とする。Obsidian や VS Code、Claude.ai と同様の構成。

### ページタイプ別レイアウト

#### 詳細ページ (Notes / Glossary / Books の各詳細)

```
┌──┬──────────┬───────────────────────────────┬──────────┐
│ア│ ツリー    │ Marg │  本文          │ Marg │ 目次     │
│イ│ + 検索    │      │                │      │ バック   │
│コ│           │      │                │      │ リンク   │
└──┴──────────┴───────────────────────────────┴──────────┘
```

- 最左: アイコンナビゲーション (Notes / Glossary / Books)
- 左サイドバー: 現在選択中のコンテンツタイプのツリー + 検索ボックス
- メインコンテンツ: 左右に Marginalia 領域を持つ
- 右サイドバー: 目次 + バックリンク

#### 一覧ページ (Notes / Glossary / Books のトップ、タグ一覧、タグ別)

```
┌──┬──────────┬───────────────────────────────────────────┐
│ア│ ツリー    │ 一覧表示                                   │
│イ│ + 検索    │                                           │
│コ│           │                                           │
└──┴──────────┴───────────────────────────────────────────┘
```

- 右サイドバーは表示しない
- メインコンテンツに Marginalia 領域は持たない (2 カラム)

#### トップページ

```
┌──┬───────────────────────────────────────────────────────┐
│ア│ 自己紹介、サイト説明、最近更新、コンテンツ入口、         │
│イ│ Featured、外部リンク                                    │
│コ│                                                        │
└──┴───────────────────────────────────────────────────────┘
```

- 左サイドバー (ツリー) は表示しない
- 右サイドバーも表示しない

## メインナビゲーション (アイコンバー)

画面最左に縦並びで配置する固定領域。

- Notes / Glossary / Books の各アイコン
- アイコンクリックで該当する一覧ページに遷移
- 現在選択中のセクションは視覚的にハイライト
- アイコンには `aria-label` と Tooltip を設定する

サイトのトップ (`/`) へのリンクとして、最上部にロゴまたはホームアイコンを配置する。

## 左サイドバー (ツリー + 検索)

現在選択中のコンテンツタイプに応じた階層ツリーを表示する。

### ツリーの構造

| コンテンツタイプ | 構造                                                                         | 表示するラベル                |
| ---------------- | ---------------------------------------------------------------------------- | ----------------------------- |
| Notes            | Vault 内のサブフォルダ構造を反映                                             | ファイル名 (= 表示タイトル)   |
| Glossary         | 五十音 (あ行 / か行 / ...) でグルーピング、`furigana` の頭文字を基準にソート | `term` または ファイル名      |
| Books            | フラット (グルーピングなし)                                                  | `aliases[0]` (メインタイトル) |

`furigana` が指定されていない Glossary 項目は「その他」セクションに分類する。

### ツリー内検索

ツリーの上部に検索入力欄を配置する。

- 入力に応じてツリーをフィルタリング (該当しない項目を非表示)
- 検索対象はファイル名 (タイトル) のみ。Books の場合は `aliases[0]`
- 入力のクリアボタンを提供

### キーボード操作

- ツリー項目間の上下移動 (Arrow Up / Down)
- Enter で該当ページに遷移
- 検索入力欄へのフォーカス移動 (`/` キーなど)

react-aria-components の Tree / TextField コンポーネントを使用し、適切な ARIA 属性を付与する。

## メインコンテンツ

### 詳細ページの本文

Markdown を変換した HTML を表示する。

- 見出し (H1-H6)、段落、リスト、引用、コードブロックなど標準的な Markdown 要素をサポート
- コードブロックは Shiki によるシンタックスハイライト付き
- 画像は `<img>` で配置 (将来的に `<picture>` 化)
- 内部リンクはサイト内ハイパーリンク、外部リンクは新規タブで開く

### Marginalia (詳細ページのみ)

メインコンテンツの左右余白に配置する補足情報。

#### 種別

| 種別              | 配置元         | スタイル                   | アイコン          |
| ----------------- | -------------- | -------------------------- | ----------------- |
| 脚注              | `[^N]` 記法    | 番号付き、小さめのフォント | なし (番号で示す) |
| Callout (note)    | `> [!note]`    | 標準的な囲み               | 情報アイコン      |
| Callout (quote)   | `> [!quote]`   | 引用風スタイル             | 引用アイコン      |
| Callout (tip)     | `> [!tip]`     | 親しみのあるスタイル       | 電球アイコン      |
| Callout (info)    | `> [!info]`    | リンク向けスタイル         | リンクアイコン    |
| Callout (warning) | `> [!warning]` | 注意を引く色               | 警告アイコン      |

種別ごとに異なるアイコンとスタイルで視覚的に区別する。

#### 配置ロジック

- 脚注は本文中の参照箇所と同じ高さに配置
- Callout は本文中で記述された位置と同じ高さに配置
- 同じ高さに複数の Marginalia がある場合は縦に並べる

#### レスポンシブ

| ビューポート        | 脚注                                     | Callout                        |
| ------------------- | ---------------------------------------- | ------------------------------ |
| 広い (デスクトップ) | 左右余白                                 | 左右余白                       |
| 中 (タブレット)     | 右余白のみ                               | 右余白のみ                     |
| 狭い (モバイル)     | ページ末尾に脚注セクションとしてまとめる | 該当箇所の直下にインライン展開 |

ブレークポイントは StyleX の Media Query で定義する。具体的なピクセル値は実装時に決定。

## 右サイドバー (詳細ページのみ)

### 目次 (TOC)

本文中の H2 と H3 を抽出して目次を構築する。

- IntersectionObserver で現在表示中のセクションを検出し、該当する目次項目をハイライト
- 目次項目クリックで該当セクションにスムーズスクロール
- 見出しが存在しない (H2/H3 がない) ページでは目次エリアを非表示にする

### バックリンク

目次の下に「このページにリンクしているページ一覧」を表示する。

- バックリンクは Notes / Glossary / Books すべてのコンテンツタイプから収集
- リンク元のタイトルとコンテンツタイプ (アイコン等) を表示
- バックリンクが存在しない場合はセクションごと非表示
- 目次が非表示の場合、バックリンクが上に詰める

## 各ページの詳細

### トップページ (`/`)

以下のセクションで構成する。

1. **自己紹介セクション**
   - サイト固有の Markdown ファイル (`_site/home.md` 等) から本文を取得
   - 名前、肩書き、専門領域、簡潔な紹介文
2. **このサイトについて**
   - サイト固有の Markdown ファイルから本文を取得
   - Digital Garden の説明、コンテンツの読み方
3. **最近更新されたコンテンツ**
   - Notes / Glossary / Books 横断、`status: published` のもののみ
   - `updated` 降順、上位 5 件
   - 各項目にコンテンツタイプ (アイコン) と更新日を表示
4. **コンテンツタイプ別の入り口**
   - Notes / Glossary / Books それぞれへの大きな導線
   - 各タイプの公開コンテンツ件数を表示
5. **Featured / Pinned コンテンツ**
   - frontmatter で `featured: true` を持つコンテンツ
   - `updated` 降順
6. **外部リンク**
   - `site.config.ts` で定義された SNS / GitHub 等へのリンク

### Notes 一覧ページ (`/notes`)

- メインコンテンツにカード型グリッドを表示
- カードに表示する情報: タイトル、summary、tags、updated
- デフォルトの並び順: `updated` 降順
- タグでの絞り込み機能を提供 (UI はメインコンテンツ上部に配置)
- ステータスでの絞り込み・並び替え切り替えはなし

### Notes 詳細ページ (`/notes/[slug]`)

- メインコンテンツ: タイトル、メタ情報 (更新日、タグ)、本文
- 右サイドバー: 目次 + バックリンク
- 本文左右余白: Marginalia

### Notes タグ一覧ページ (`/notes/tags`)

- Notes 内で使用されているすべてのタグを表示
- 各タグの使用件数を併記
- タグ名アルファベット順 / 使用件数降順 などソート方式は実装時に決定 (デフォルト: 使用件数降順)

### Notes タグ別一覧ページ (`/notes/tags/[tag]`)

- 該当タグを持つ Notes の一覧 (カード型グリッド)
- 階層タグの場合、親タグでフィルタすると子タグを持つ Notes も含める

### Glossary 一覧ページ (`/glossary`)

- 五十音 / アルファベット順のインデックス表示
- 「あ行」「か行」... のように見出しでグルーピング
- 頭文字 (あ行 / か行 / ...) によるジャンプリンクをページ上部に配置
- 用語ごとに `term`、`summary` (あれば)、`tags` を表示

### Glossary 詳細ページ (`/glossary/[slug]`)

- メインコンテンツ: 用語名、ふりがな、aliases、本文
- 右サイドバー: 目次 (見出しが少ないことが多いため、ない場合は非表示) + バックリンク
- 本文左右余白: Marginalia

### Glossary タグ一覧 / タグ別ページ

Notes と同様の構成。

### Books 一覧ページ (`/books`)

- カード型グリッド
- カードに表示する情報: 書影 (`cover` 指定があれば)、タイトル (`aliases[0]`)、著者、summary
- デフォルトの並び順: `pubYear` 降順
- 書影がない場合は代替表示 (タイトル + 著者のみのプレースホルダ)

### Books 詳細ページ (`/books/[isbn]`)

- メインコンテンツ: 書影 (あれば)、タイトル、著者、出版社、発行年、読了日、ISBN、本文
- 右サイドバー: 目次 + バックリンク
- 本文左右余白: Marginalia

### Books タグ一覧 / タグ別ページ

Notes と同様の構成。

### 404 ページ (`/404`)

シンプルな専用ページ。トップページへの導線を含む。

## アクセシビリティ

WCAG 2.2 AA 準拠を目標とする。

- すべてのインタラクティブ要素に適切な ARIA 属性を付与
- キーボードのみで全機能を操作可能
- フォーカスインジケータの視覚的明示
- カラーコントラスト比の確保 (テキスト 4.5:1 以上、大きいテキスト 3:1 以上)
- 動きを減らすユーザー設定 (`prefers-reduced-motion`) に対応

react-aria-components の使用により、多くのアクセシビリティ要件はライブラリ側で担保される。

## ダークモード

OS 設定への追従とトグル切り替えの両方をサポートする。

- 初回訪問時は OS の `prefers-color-scheme` に従う
- ヘッダー / ナビゲーション内にトグルを配置 (具体的な位置は実装時に決定)
- ユーザーの選択は localStorage に保存
- StyleX のテーマトークン機能で配色を管理

## レスポンシブ

| ブレークポイント | 想定ビューポート | レイアウトの主な変化                                           |
| ---------------- | ---------------- | -------------------------------------------------------------- |
| Desktop (広い)   | 1280px〜         | 詳細ページで Marginalia を左右両方に配置                       |
| Desktop (中)     | 1024px〜1279px   | Marginalia を右側のみに                                        |
| Tablet           | 768px〜1023px    | 左サイドバー (ツリー) を折りたたみ可能に                       |
| Mobile           | 〜767px          | 左サイドバー / 右サイドバーをハンバーガーメニュー / ドロワーに |

正確なブレークポイント値は実装時に StyleX の Media Query 定義で決定する。

## OGP / メタタグ

- サイト共通の固定 OGP 画像を 1 枚用意
- 各ページの `<title>` および `<meta name="description">` は動的に生成
- `og:title`、`og:description`、`og:type`、`og:url`、`twitter:card` の各種メタタグを生成

ページごとの動的 OGP 画像生成は初期段階では行わない。
